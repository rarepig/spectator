# Spectator

2023년에 작성한 Windows용 League of Legends 관전·방송 보조 프로그램의 소스 코드입니다. Flask로 만든 로컬 조작 화면에서 선수를 관리하고, 경기 관전과 방송 화면 조작을 자동화합니다.

## 주요 기능

- 딥롤 사이트 내부 요청을 이용한 선수·소환사 정보 수집
- Riot 경기 정보 조회 및 수동·자동 관전
- 화면 캡처와 Google Vision / Clova OCR을 이용한 선수 인식
- 키보드·마우스를 이용한 관전 화면 제어
- PyQt 기반 방송 오버레이와 Spotify 곡 정보 표시

## 소스 구성

| 파일 | 역할 |
| --- | --- |
| `main.py` | 프로그램 실행 진입점 |
| `server.py` | Flask 화면과 요청 처리, 자동 관전 작업 |
| `utils.py` | 외부 데이터 조회, 선수 관리, 관전 실행 |
| `player_all.py` | 선수 목록 일괄 수집 |
| `ingame.py` | 게임 화면 인식 및 입력 자동화 |
| `ocr.py` | OCR 서비스 연동 |
| `overlay.py` | 방송용 정보 표시 |
| `musictitle.py` | Spotify 재생 정보 표시 |
| `timer.py`, `bctimer.py` | 타이머 도구 |

## 프로젝트 상태

과거 구현을 보존하기 위한 공개본입니다. 현재 게임 클라이언트·외부 서비스와의 호환성 및 정상 동작은 검증하지 않았습니다. Windows 전용 기능과 화면 좌표에 의존하며, macOS에서 전체 프로그램을 실행할 수 없습니다.

명령어 삽입 방어, HTML 입력 처리, CSRF 방어와 작업 중복 실행 방지 등은 아직 보완하지 않았습니다. 인터넷이나 공용 네트워크에 서버를 노출하지 마세요. 소스 검토 없이 실행하는 것은 권장하지 않습니다.

`player_all.py`는 실행 시 외부 조회 후 로컬 선수 목록을 덮어씁니다. `main.py`는 별도로 빌드된 실행 파일을 호출합니다. 이 저장소에는 실행 파일을 포함하지 않습니다.

## 설정 및 제외 파일

`settings.example.json`은 빈 인증정보를 가진 설정 형식 예시입니다. 실제 사용 시 로컬에서 `settings.json`으로 복사해 사용해야 합니다. 인증정보·토큰·Google 서비스 계정 파일은 공개 대상에서 제외했습니다. 기존 키의 서비스 측 폐기는 별도로 필요합니다.

다음 파일도 공개 대상에서 제외했습니다.

- 실행 파일, 빌드 결과 및 Python 캐시
- 화면 캡처, OCR 결과, 개발용 미리보기
- 저장된 선수 목록과 방송 상태
- 게임 데이터·이미지·폰트 등 재배포 권한을 확인하지 않은 리소스

따라서 이 공개본은 바로 실행되는 배포 패키지가 아닙니다. 외부 리소스와 인증정보, 실행 환경을 별도로 준비하고 보안 문제를 수정해야 합니다. 원본 패키지 버전 기록이 없어 검증되지 않은 의존성 버전 목록은 제공하지 않습니다.

## 외부 서비스와 권리

League of Legends 및 관련 리소스, 딥롤, Spotify, OCR 서비스의 권리는 각 권리자에게 있습니다. 외부 데이터 수집·이용 및 리소스 재배포에는 해당 서비스의 이용 조건과 권한을 별도로 확인해야 합니다. 본 프로젝트는 해당 서비스의 공식 제품이 아닙니다.
